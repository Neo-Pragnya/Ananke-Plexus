# Security policy

## Supported versions

Only the [latest release on PyPI](https://pypi.org/project/ananke-plexus/) gets fixes.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/Neo-Pragnya/Ananke-Plexus/security/advisories/new). Don't open a public issue.

Please include the affected version, how to reproduce it, the impact, and a suggested fix if you have one.

We aim to reply within 7 days and to publish a fix within 30 days of confirming a problem, and we'll credit you unless you'd rather we didn't. Fixes are announced in the [changelog](CHANGELOG.md) and as [security advisories](https://github.com/Neo-Pragnya/Ananke-Plexus/security/advisories).

## What's in scope

Reading a repository you don't trust is meant to be safe: Ananke's analysis reads files and runs nothing from them, and links can't lead its writes elsewhere. A way around that is a vulnerability.
